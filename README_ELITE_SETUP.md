# ClearStay Analytics — Elite Multi-Page Site (No Assets Folder Needed)

This version does not require an assets folder. The logo is built with CSS, so you only need to upload the files at the root of the repo.

Upload these files directly into your GitHub repository root:

- index.html
- services.html
- str-analytics.html
- small-business.html
- pricing.html
- sample-report.html
- resources.html
- about.html
- contact.html
- case-study.html
- privacy.html
- 404.html
- styles.css
- script.js
- robots.txt
- sitemap.xml
- README_ELITE_SETUP.md

Do not upload the zip itself. Do not place the files inside a parent folder.

After uploading, go to Settings → Pages → Deploy from a branch → main → /root → Save.

Replace placeholders before sharing the site:

- YOUR_GOOGLE_FORM_LINK
- YOUR_BOOKING_LINK
- YOUR_EMAIL@gmail.com
